# murli - AI-Powered Project Generator

> Generate full-stack project boilerplates instantly with AI

## 🎯 What is murli?

murli is an AI-powered web platform designed for students that automatically generates ready-to-use full-stack project boilerplates. Simply configure your tech stack, define your database schema, and let AI create a complete, working project for you.
